01

The Productivity Fatigue Problem

Traditional to-do list applications often suffer from high user drop-off and procrastination due to rigid, uninspiring design patterns:

  • Chore Association & Guilt: Standard checklists feel like an exhausting wall of obligations, creating friction and task aversion rather than proactive momentum.
  • Missing Dopamine Reinforcement: Checking off an item offers zero feedback or sense of growth, failing to leverage positive behavioral gamification loops.
  • Network Latency & Cloud Clutter: Many modern productivity apps require complex cloud accounts, experiencing startup lag and failing during offline transit.
  • Disjointed Task Breakdown: Users struggle when large goals lack progressive subtasks with visible micro-progress indicators.

Engineering Overview • Synopsis

Software Architecture & System Overview

TASUKU is structured around a decoupled multi-layer Flutter architecture that separates UI presentation widgets, reactive state management (Provider), local NoSQL persistence (Hive), and background system services (Local Notifications). This design ensures that high-frequency UI animations run at a smooth 60fps without triggering unnecessary database reads or widget tree re-evaluations.

Core System Subsystems

Subsystem 01

Gamified Quest & Level Engine

Formulates user level through mathematical progression: (completedCount ~/ 3) + 1. Updates EXP bar in real-time upon completing or reopening quests.

Subsystem 02

Nested Subtask Checklists

Encodes checklist items into structured JSON strings on TaskModel. Automatically evaluates dynamic completion ratios (completedSubtasks / totalSubtasks).

Subsystem 03

Hive NoSQL Storage Engine

Generates compile-time binary type adapters via build_runner. Performs instant in-memory CRUD operations and auto-saves state modifications directly to disk.

Subsystem 04

Timezone Reminder Alerts

Initializes timezone databases to register native exact alarms via zonedSchedule, generating distinct notification IDs from hash codes to reliably fire even when idle.

Subsystem 05

Table Calendar Planning

Integrates customizable calendar headers and date marker decorators. Allows users to switch between monthly and bi-weekly views to quickly inspect missions scheduled on specific dates.

Subsystem 06

FL Chart Weekly Analytics

Aggregates completed vs pending task metrics across 7-day intervals. Renders clean bar and line charts to give users clear visibility into their daily productivity habits.

lib/models/task_model.dart • Subtask Progress Calculation
Dart • HiveObject 
@HiveType(typeId: 0)
class TaskModel extends HiveObject {
  @HiveField(0) String id;
  @HiveField(1) String title;
  @HiveField(3) DateTime dueDate;
  @HiveField(5) bool isDone;
  @HiveField(9) String subtasksRaw;

  // Dynamic subtask checklist progress calculation
  int get totalSubtasks => subtasks.length;
  int get completedSubtasks => subtasks.where((s) => s.isDone).length;
  double get subtaskProgress =>
      totalSubtasks == 0 ? 0.0 : completedSubtasks / totalSubtasks;
}
