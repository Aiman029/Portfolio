01

The Client's Operational Bottlenecks

During our initial observation and stakeholder interview with Encik Syukri (owner of Kita Konbini Minimart at UPSI), we identified critical manual bottlenecks that degraded student shopping efficiency and inventory control:

  • Manual Stock Ledger Errors: Physical stock counts relied on handwritten tally sheets, causing severe count discrepancies and untracked shrinkages.
  • In-Store Shelf Location Friction: Students spent excessive time roaming aisles searching for specific imported snacks, instant noodles, or stationery items.
  • Peak Hour Counter Congestion: Long checkout queues formed between lectures due to manual cash collection and paper receipts.
  • Zero Real-Time Sales Intelligence: Store management had no automated reporting to identify fast-moving products or predict reorder dates.
02

The Digitalized Web Solution

We designed a centralized, database-backed web management platform fulfilling all 20 IEEE-standardized Software Requirements Specifications (SRS):

In-Store Product Shelf Locator

Integrated shelf location tags (e.g. "Aisle 3 • Shelf B") on every product card, allowing students to instantly locate items physically in the store.

Automated Stock & Low-Stock Alerts (FR006)

Real-time inventory decrementing with non-negative constraints (CR008) and automated alerts notifying staff when stock reaches critical thresholds.

Digital Checkout & Receipts (FR017/FR018)

Streamlined cart checkout with unique immutable receipt numbers (CR013), eliminating paper waste and speeding up transactions.

Executive Revenue Analytics (FR019/FR020)

Real-time dashboards aggregating total revenue, daily gross volume, and top-selling product categories for data-driven restock decisions.

Software Design Description (SDD)

Three-Tier Architecture & Database Design

The Kita Konbini Minimart Management System strictly adheres to a modular three-tier architecture (User Layer, Application Layer, Data Layer) to guarantee separation of concerns, high maintainability, and data consistency under concurrent traffic.

[Presentation Layer]

User Layer (Blade & CSS/JS)

Responsive browser client offering tailored view hierarchies for Customers (catalog browsing, wishlists, cart checkout) and Administrators (inventory controls, price editing, sales reporting).

Mobile-optimized Blade templates • Tailwind styling
[Business Logic Layer]

Application Layer (Laravel 10)

Modular controllers managing Account Management, Product Inventory, Payment Processing, Notification Triggers, and Sales Analytics. Enforces authentication middleware and transaction boundaries.

Eloquent ORM • Middleware Auth • Service Interfaces
[Persistence Layer]

Data Layer (MySQL DBMS)

Centralized relational schema organized into 7 core tables: User, Product, Cart, Payment, Receipt, Notification, and Sales.

ACID compliance • Foreign keys • Audit logging (CR006)

OrderCheckoutController.php (Transactional Integrity) PHP 8.2 • Laravel Eloquent Transaction 
public function processOrder(CheckoutRequest $request)
{
    // Enforce ACID transactional consistency (CR008, CR013, CR017)
    return DB::transaction(function () use ($request) {
        $cartItems = Cart::where('user_id', auth()->id())->lockForUpdate()->get();

        foreach ($cartItems as $item) {
            $product = Product::findOrFail($item->product_id);
            
            // CR008: Stock quantities must not become negative
            if ($product->stock_quantity < $item->quantity) {
                throw new InsufficientStockException("Insufficient stock for: {$product->name}");
            }
            $product->decrement('stock_quantity', $item->quantity);
        }

        // CR013: Auto-generate unique receipt and record immutable payment
        $payment = Payment::create([ ... ]);
        $receipt = Receipt::create([
            'receipt_no' => 'KB-' . strtoupper(Str::random(8)),
            'payment_id' => $payment->id
        ]);

        Cart::where('user_id', auth()->id())->delete();
        return response()->json(['receipt' => $receipt], 200);
    });
}
