01

The Pedagogical Challenge

Malaysian secondary school history (Sejarah) is frequently regarded by students aged 13–17 as one of the most challenging academic subjects due to traditional teaching limitations:

  • Passive Rote Memorization: Static textbooks and repetitive notes discourage critical inquiry, resulting in poor conceptual retention of historical timelines and events.
  • Delayed Formative Feedback: Traditional paper exercises fail to provide immediate diagnostic explanations when students select incorrect answers.
  • Absence of Gamified Motivation: Without healthy peer benchmarks, countdown pacing, or ranking leaderboards, students lack the enthusiasm needed for self-directed revision.
  • Lack of Mnemonic Study Strategies: Students rarely receive structured guidance on mnemonic techniques, exam answering strategies, or chronological chunking methods.
02

The Digitalized Edutainment Solution

Developed as an independent software engineering initiative (no external client), Mudah Sejarah unites curriculum-aligned content with modern web interactivity:

Era-Based Interactive Learning Directory

Structured modules covering Kesultanan Melayu Melaka, Penjajahan Portugis & Belanda, Perjuangan Kemerdekaan, and Malaysia Merdeka with key learning objectives.

Dynamic 10-Question Randomized Quiz Engine

Extracts 10 randomized questions from a 50-item question repository per session, pairing countdown timing with immediate answer verification.

In-Depth Diagnostic Answer Recap

Breaks down question results immediately upon completion, highlighting mistakes and providing corrective rationales to solidify understanding.

Multi-Interval Scoreboard & Student Analytics

Time-filtered leaderboard queries (Today, Week, Month, All-Time) paired with individual student profile analytics tracking attempts, averages, and best scores.

Engineering Overview • Synopsis

Three-Tier Architecture & System Synopsis

The Mudah Sejarah system adopts a decoupled three-tier architectural model separating the browser presentation layer, PHP backend REST endpoints, and MySQL relational database. Designed without external client entanglements, the application enforces separation of concerns to provide low latency, high maintainability, and friction-free accessibility across desktop and mobile browsers.

[Presentation Layer]

Client UI (Vanilla HTML5 & ES6)

Engineered using modular ES6 JavaScript controllers (quiz.js, scoreboard.js, auth.js), semantic HTML5, and responsive CSS. Features an interactive Malaysian heritage particle canvas that runs at 60fps without heavy client-side libraries.

Zero Bloat • Asynchronous Fetch API • 60fps Canvas
[Application & Logic Layer]

RESTful Web Services (PHP 8.x)

Stateless PHP API endpoints handling BCrypt password verification, session authentication, incoming quiz submission processing, dynamic score persistence, and interval-filtered leaderboard ranking queries with structured JSON responses.

JSON REST APIs • BCrypt Hashing • CORS Headers
[Persistence Layer]

Relational Data Layer (MySQL)

Centralized MySQL database with utf8mb4 character encoding. Employs relational primary/foreign key integrity connecting student credentials (users) with cumulative quiz submissions (quiz_scores).

Normalized Tables • Index Optimization • Temporal Queries

Core System Subsystems

Subsystem 01

Dual-Tier Authentication

Allows guest users to explore educational notes and practice quizzes with zero friction, while authenticated students enjoy persistent score recording and personalized historical dashboards.

Subsystem 02

Era Learning Material

Categorized historical content directory organized across 4 major eras. Includes explicit learning objectives and automatic prompts directing students to the chapter quiz upon topic completion.

Subsystem 03

Randomized Quiz Generator

Client-side algorithm that pulls 10 randomized questions from a 50-item question repository. Coordinates countdown timing, answer selection state, and immediate result grading.

Subsystem 04

Time-Filtered Scoreboard

Server-side SQL query filtering by date intervals (Today via CURDATE(), Week via 7-day intervals, Month via 30-day intervals, and All-Time) to foster ongoing peer motivation.

Subsystem 05

Tutorial & Mnemonic Engine

Educational strategy center providing actionable study tips (Cara Pembelajaran), examination technique guidance (Tips Peperiksaan), and memory association frameworks (Teknik Hafalan).

Subsystem 06

Student Profile & Stats

Aggregated student metrics calculating total quizzes taken, cumulative average score, and personal best score, paired with a chronological review log of past attempts.

api/get_scoreboard.php (Temporal SQL Ranking) PHP 8.x • MySQL Interval Aggregation 
// Dynamic Temporal Leaderboard Query with SQL Interval Constraints
$filter = isset($_GET['filter']) ? $_GET['filter'] : 'all';
$limit  = isset($_GET['limit'])  ? (int)$_GET['limit'] : 20;

$sql = "SELECT u.id, u.username, u.email, qs.score, qs.created_at
        FROM quiz_scores qs
        JOIN users u ON qs.user_id = u.id";

switch ($filter) {
    case 'today':
        $sql .= " WHERE DATE(qs.created_at) = CURDATE()";
        break;
    case 'week':
        $sql .= " WHERE qs.created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)";
        break;
    case 'month':
        $sql .= " WHERE qs.created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)";
        break;
}

$sql .= " ORDER BY qs.score DESC, qs.created_at ASC LIMIT $limit";
