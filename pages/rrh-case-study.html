The Educational Challenge

In primary school education (ages 7 to 12), traditional passive reading of fairy tales often fails to sustain long-term reading engagement. Research demonstrates that children experience rapid retention decay when narrative content is presented solely through static text without active retrieval opportunities.

  • Attention Fragmentation: Static text cannot compete with rich interactive digital mediums for modern digital-native pupils.
  • Passive Cognitive Consumption: Without formative checkpoint questions, students skip over moral nuances and vocabulary development.
  • Memory Decay: Story details blur quickly unless organized through systematic cognitive chunking techniques.
02

The Multi-Sensory Solution

We developed a comprehensive educational package integrating three validated pedagogical theories to transform the classic Little Red Riding Hood tale into an active learning journey:

Dual Coding Theory (Paivio)

Synchronous visual animations, auditory voiceover narration, and text subtitles stimulate both verbal and non-verbal processing channels simultaneously.

Cognitive Chunking ("RIDING")

Deconstructs the narrative into 6 digestible chronological milestones mapped to each letter of "RIDING", dramatically lowering extraneous cognitive load.

Formative Retrieval Practice

Immediate gamified quiz challenges reinforce plot recall and vocabulary through spaced difficulty progression and instant feedback.

Cognitive Architecture

The "R-I-D-I-N-G" Mnemonic Framework

An original instructional design heuristic created for the DEP project, allowing students to effortlessly retain the entire moral and narrative structure.

R
Red Sets Off

Little Red Riding Hood embarks on her journey through the woods carrying fresh baked goods in her basket to visit her ailing Grandmother.

I
Ignores Danger

She violates her mother's cautionary advice by interacting freely with an unknown predator—the sly Big Bad Wolf in the dark forest.

D
Deceived By Wolf

The wolf tricks her into picking wild flowers along the distant path while he races ahead directly to Grandmother’s cottage.

I
Identifies Wrong

Arriving at the cottage, she observes anomalous physical traits ("What big eyes you have! What big teeth you have!").

N
Needs Help & Shouts

As the disguised wolf lunges forward, Red urgently raises her voice, alerting the nearby forest inhabitants to the danger.

G
Gets Saved

A brave woodcutter overhears the cry, rushes in to incapacitate the beast, and safely rescues both Red and her Grandmother.

Software Architecture

Technical Engineering & C# Implementation

As the primary Game Programmer on the team, my responsibility was establishing the underlying C# software architecture, implementing state machine controllers, dynamic quiz logic, and seamless synchronization between narration audio and subtitle rendering.

[State Pattern]

Finite State Machine (FSM)

Orchestrated five decoupled game phases using strict state boundaries: MainMenuState, StoryState, MnemonicState, QuizState, and ResultsState.

Prevents scene leakages & invalid button triggers
[Assessment Engine]

Dynamic Quiz Evaluator

Built randomized question selection algorithms from structured question arrays. Implemented button shuffle logic to prevent positional memorization, accompanied by immediate audio/visual score feedback.

Fisher-Yates shuffle & difficulty weighting
[Multimedia Controller]

Audio-Subtitle Sync Bridge

Engineered real-time timestamped event triggers matching narration voice tracks with on-screen subtitle strings. Integrated user transport controls (Play, Pause, Fast-Forward, Stop, Mute).

WCAG-compliant high-contrast subtitles

public enum GameState { MainMenu, StoryNarrative, MnemonicLearning, QuizEvaluation, PerformanceMark }

public class QuizGameManager : MonoBehaviour
{
    public GameState CurrentState { get; private set; }
    private int score = 0;
    private QuestionData[] activeQuestions;

    public void TransitionTo(GameState nextState)
    {
        // Teardown current screen controllers safely
        ExitCurrentState(CurrentState);
        CurrentState = nextState;
        EnterNewState(nextState);
    }
